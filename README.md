# Многошаговое планирование поверх FB-представлений

Решение тестового задания по статье *Switching Successor Measures for
Hierarchical Zero-shot Reinforcement Learning*. Задача — придумать
high-level механизм, который рассуждает не об одном шаге вперёд, а о
последовательности шагов, и сравнить его с готовым жадным бейзлайном на
`antmaze-medium-navigate-v0`.

Полная история экспериментов (что пробовал, что не сработало и почему) —
в [`REPORT.md`](REPORT.md). Здесь — только суть и как всё запустить.

## Идея решения одной строкой

Жадный бейзлайн выбирает лучший следующий шаг по одной формуле из статьи
(switching advantage) и ни разу не заглядывает дальше. Финальное решение
строит граф из реально пройденных переходов в датасете — это даёт
маршрут, который честно обходит стены лабиринта, — а формулу из статьи
использует только для выбора лучшего варианта среди уже гарантированно
достижимых точек. Перед этим было испробовано ещё десять разных идей —
все они и почему не сработали разобраны в `REPORT.md`.

## Итоговый результат

| Метод | Success rate | Доверительный интервал (95%) |
|---|---|---|
| Готовый бейзлайн (жадный, single-intention) | 0.670 | [0.578, 0.762] |
| **Мой метод (граф + FB)** | **0.520** | **[0.422, 0.618]** |

Метод в среднем уступает бейзлайну, но на одной из пяти задач среды
(там, где путь до цели самый запутанный) он его обгоняет — 0.85 против
0.70. Подробный разбор по каждой задаче — в `REPORT.md`.

## Соответствие условиям задания

- Используются только F, B, π_l и офлайн-датасет — никакой карты стен
  или другой скрытой от агента информации о лабиринте.
- Граф строится из реальных переходов датасета — это справочная таблица,
  а не генеративная модель, ничего не выдумывает.
- Никакого нового взаимодействия со средой для обучения — граф и все
  расчёты делаются офлайн.
- F, B и π_l не переобучались — использовались ровно в том виде, в каком
  выданы в чекпоинте.

```

├── run_graph_eval.py                        ← оценка финального метода

```

## Как запустить

```bash
python3.12 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install "jax>=0.4.38" "flax>=0.10.2" "distrax>=0.1.5" \
    "gymnasium==0.29.1" "ml_collections>=1.1.0" "ogbench==1.1.4" \
    "h5py==3.12.1" "wandb>=0.19.11" numpy

mv checkpoints/params.pkl checkpoints/params_1000000.pkl   # если ещё не переименован

python3 run_compare_eval.py     # оба метода сразу, ~25-35 минут, все 5 задач
```

Датасет OGBench скачается автоматически при первом запуске. Каждая
задача оценивается на 20 сидах, всего 100 испытаний на метод.

## Ограничения

- Проверено только на `antmaze-medium-navigate-v0`; более сложные
  варианты среды (teleport/large/giant) не тестировались из-за нехватки
  времени.
- При повторных запусках одних и тех же сидов результат отдельного
  эпизода иногда чуть отличается (вероятно, из-за многопоточных
  вычислений с плавающей точкой) — поэтому все итоговые цифры считаются
  по большому числу независимых испытаний, а не по одному прогону.
